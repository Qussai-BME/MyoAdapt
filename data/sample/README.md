# Sample data

This directory contains small synthetic EMG-like datasets used by the
quickstart smoke tests, the CLI integration tests, and the API integration
tests. None of the files here are real subject recordings — they are
procedurally generated numpy arrays with the right shape for the NinaPro
DB2 schema (12 channels, 2000 Hz) so that downstream code can exercise the
full preprocessing + feature-extraction + training + inference pipeline
without requiring any external data download.

## Files

- `smoke_test.npz` — generated by `scripts/make_sample_data.py`. Schema:

  | key           | shape                          | dtype   | description                                 |
  | ------------- | ------------------------------ | ------- | ------------------------------------------- |
  | `windows`     | `(N, 12, 400)`                 | float32 | 200-ms EMG windows, 12 channels, 2000 Hz    |
  | `labels`      | `(N,)`                         | int32   | gesture label per window                    |
  | `groups`      | `(N,)`                         | int32   | subject id per window                       |
  | `databases`   | `(N,)`                         | int32   | database id per window (for LODO tests)     |
  | `fs`          | `()`                           | int32   | sampling rate in Hz                         |
  | `n_channels`  | `()`                           | int32   | number of channels                          |

  For the default smoke-test payload: 5 subjects × 5 gestures × 10 windows
  = 250 windows, distributed across 3 synthetic databases.

## Regenerating

```bash
python scripts/make_sample_data.py
```

The script is deterministic (`random_state=42`) so re-running it produces a
byte-identical file, which keeps CI snapshots reproducible.
